# Istruzioni per gli agenti

Prima di modificare codice, esamina struttura, file pertinenti e convenzioni del repository; applica anche gli `AGENTS.md` delle cartelle interessate.

## Guide per attività

Prima delle attività seguenti, consulta la guida indicata, se presente, e applicala insieme alla richiesta dell'utente:

| Attività | Guida |
| --- | --- |
| Initial Setup | `project-guides/initial-setup.md` |
| Scrivere o aggiornare test | `project-guides/test-prompt.md` |
| Revisionare una PR | `project-guides/pr-revision-prompt.md` |
| Scrivere o modificare codice | `project-guides/clean-code-principles.md` |
| Preparare o creare una PR | `project-guides/pull-request-creation-prompt.md` |
| Preparare un commit | `project-guides/commit-best-practices.md` |
| Creare o rinominare un branch | `project-guides/branch-name-best-practices.md` |

Se manca una guida o `project-guides/`, procedi con istruzioni e contesto disponibili; non dichiarare di aver consultato o applicato contenuti assenti.
